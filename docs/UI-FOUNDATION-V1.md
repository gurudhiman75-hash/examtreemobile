# ExamTree Mobile UI Foundation V1

Status: implementation branch baseline

This file marks the first UI-focused implementation slice after authentication, navigation, networking and APK-signing stabilization.

Goals:
- align the live Flutter theme with the approved deep-indigo + teal product direction;
- make typography denser and more deliberate on phone screens;
- standardize buttons, cards, inputs, chips, navigation and progress indicators;
- reduce decorative chrome and improve first-viewport information hierarchy;
- preserve existing routes, auth, API contracts and canonical data behavior.

This slice intentionally changes presentation only. Learner-data rules and backend behavior are out of scope.
