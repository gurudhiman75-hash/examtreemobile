# Exam-Day Mode validation checklist

- Flutter analysis must be clean.
- Complete Flutter test suite must pass.
- Android debug build must compile launcher shortcut and notification integration.
- Countdown stage tests must remain deterministic.
- Reminder denial must disable the persisted reminder flag.
- Logout must cancel exam-day reminders.
- Sign-in must restore reminders only for the signed-in user's saved target.
- Official-instructions and non-readiness wording must remain present.
